## 📖 About

**Maxwheels** is a fully responsive, automobile-themed car dealership website — built as the **Semester 1 Internet & Web Technology (IWT)** project. It goes well beyond a basic HTML page: it includes a Swiper.js carousel for featured cars, a parallax scroll effect on the hero section, a slide-in login popup, Font Awesome icons throughout, and a multi-section layout covering home, vehicles, services, featured, reviews, and contact.

---

## ✨ Features

- **Swiper Carousel** — Smooth touch/swipe car showcase using Swiper.js v7
- **Parallax Scroll Hero** — `data-speed` attributes drive layered parallax effect on the home section
- **Slide-in Login Modal** — Overlay login form with email/password, social login buttons, and a sign-up link
- **Responsive Navigation** — Hamburger menu (`fa-bars`) for mobile, full horizontal nav on desktop
- **Multi-Section Layout** — Home, Vehicles, Services, Featured, Reviews, Contact
- **Font Awesome Icons** — Used for menu toggle, user icon, and feature icons
- **No CSS Framework** — All responsive styling is hand-written CSS
